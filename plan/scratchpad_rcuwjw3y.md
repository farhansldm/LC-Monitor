## Feature Comparison Report: LC Monitor vs Handdy

### 1. Overview
*   **LC Monitor**: A web-based workforce monitoring dashboard + Chrome Extension client. Includes built-in team collaboration tools (chat, voice/video calls) and project/task management (Kanban board).
*   **Handdy**: A specialized employee monitoring, time tracking, and productivity analytics software consisting of a web dashboard and a multi-OS Desktop Timer (Windows, Mac, Ubuntu Linux).

---

### 2. Features Present in Both (Overlap)
*   **Time & Attendance tracking**: Both systems monitor login/logout (clock in/out) times, break times, and generate timesheet reports showing total daily/weekly/monthly work hours.
*   **Website Usage / Browser History**: Both systems capture websites visited by the employee.
    *   *LC Monitor* uses a Chrome Extension.
    *   *Handdy* uses a desktop application.
*   **Screenshot Capture**: Both systems capture periodic screenshots of the employee's screen.
    *   *LC Monitor* has this feature planned (15-minute screenshots via Chrome Extension).
    *   *Handdy* has this fully implemented in its Premium and Enterprise plans (via Desktop App).
*   **Manager/Admin Dashboard**: Centralized console for tracking teams, adding employees, setting configurations, and analyzing reports.

---

### 3. LC Monitor Extra Features (Absent in Handdy)
These features are unique to LC Monitor and are not offered by Handdy:
*   **Internal Real-time Chat**: LC Monitor has an internal team chat system built into the platform. Handdy does not provide any communication capabilities.
*   **Voice & Video Calling (WebRTC)**: LC Monitor supports voice and video calls for team collaboration directly in the browser. Handdy does not.
*   **Kanban Task Board**: LC Monitor includes a functional Kanban board to manage, assign, and track project tasks visually. Handdy only tracks *time spent* on tasks but does not feature a Kanban project management tool.
*   **Chrome Extension Client**: Purely browser-based client (lightweight extension). Handdy requires a desktop agent download/installation.

---

### 4. Handdy Extra Features (Absent in LC Monitor)
These features are offered by Handdy but are not present in LC Monitor:
*   **Application/Software tracking**: Handdy tracks usage of native desktop applications (e.g. Photoshop, VS Code, Word, Excel). LC Monitor only tracks browser history.
*   **Keystroke Activity Monitoring**: Handdy tracks the frequency/intensity of keystrokes and mouse clicks to detect employee activity vs. idleness. LC Monitor does not track user activity level.
*   **Offline Tracking**: Handdy tracks time, websites, app usage, and screenshots even without internet connectivity, syncing the data once online. LC Monitor's extension does not currently have offline sync capability.
*   **Productivity Categorization**: Handdy allows classification of apps and websites (e.g., productive, unproductive, neutral) to calculate automated productivity scores. LC Monitor does not categorize URLs.
*   **IP Restriction**: Handdy allows restricting time tracking to authorized corporate IP addresses.
*   **Multi-OS Desktop Client**: Handdy has native clients for Windows, Mac, and Ubuntu Linux to monitor all OS-level actions.
